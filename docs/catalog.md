# 分类索引

完整保留 2026-10-11 收录快照中的项目、Skill 明细、内部预设与许可标注。这里按用途组织入口，不代表重新核验了所有上游项目。

| 分类 | 收录内容 |
| --- | --- |
| [多风格合集](catalog/collections.md) | 一个仓库覆盖多种视觉方向。独立 Skill 与内部风格预设分别列出。 |
| [纸艺、拼贴与 Zine](catalog/zine.md) | 撕纸边缘、纸张肌理、照片锚点、剪纸与杂志式编排。 |
| [极简与抽象](catalog/minimal.md) | 将照片提炼成少量形状、视觉隐喻、留白与编辑排版。 |
| [照片与插画双联](catalog/diptych.md) | 同一来源的真实照片与插画、抽象画或纸面研究稿并置。 |
| [旅行卡片、明信片与贴纸](catalog/travel.md) | 适合旅行记录、月度回忆、明信片与贴纸套装。 |
| [水彩、钢笔与手绘](catalog/painting.md) | 松散速写、铅笔、水彩、钢笔和选择性细节。更多水彩、水粉、厚涂油画见多风格合集中的 GZ-L 与 PosterLoom。 |
| [东方水墨](catalog/ink.md) | 东方留白、水墨笔触与照片双联。 |
| [版画、Riso 与网点印刷](catalog/print.md) | 少色印刷、套色偏移、网点、复古制版与印刷肌理。 |
| [印章与记忆档案](catalog/archive.md) | 照片、橡皮章、手账、色卡与档案式版面。 |
| [扁平与几何插画](catalog/flat.md) | 大色块、简化轮廓、几何构成与稚拙插画。 |
| [超现实与波普拼贴](catalog/surreal.md) | 尺度错置、戏剧布景、趣味物件与高饱和色彩。 |
| [真实照片加涂鸦](catalog/doodle.md) | 保留真实摄影环境，叠加手绘角色、线条或局部重绘。 |
| [人像、宠物与 IP](catalog/portrait.md) | 头像、动漫化、Q 版角色、宠物画像与角色衍生物。 |
| [像素与 CRT](catalog/pixel.md) | 8-bit、复古显示器、荧光栅格、余辉与翻拍质感。 |
| [摄影、胶片与电影](catalog/cinema.md) | 胶片色调、夜景氛围、慢快门、电影静帧与电影海报。 |
| [文化、建筑与物件设计](catalog/objects.md) | 建筑与工艺海报、材质艺术、色板及黑胶唱片包装。 |
| [艺术指导与系列工作流](catalog/workflow.md) | 选片、风格路由、系列一致性与质量审核；这些是工作流能力，并非都对应独立视觉风格。 |
| [扩展插画预设](catalog/illustration-library.md) | 以主题生图为主的插画风格库，纳入照片工作流时需要补充照片分析与主体保留规则。 |
| [代码绘画与本地渲染](catalog/code.md) | 使用 SVG、HTML/CSS、Python 等生成画面；不一定依赖图像生成模型，也不一定是直接的照片滤镜。 |
| [生成后端、提示词与索引](catalog/resources.md) | 帮助发现风格或执行图像生成的辅助资源，单独列出，不与照片风格 Skill 混算。 |
